# MyStore E-Commerce App

A modern responsive e-commerce web application built with Next.js and Tailwind CSS.

## Live Demo

https://mye-comm.netlify.app

##GitHub Repository

https://github.com/Victoria20-me/E-commerce-project

## Features

- Browse products
- Search products instantly
- Filter by category
- Product details page
- Add to cart
- Cart quantity controls
- Remove items from cart
- Wishlist functionality
- Product ratings
- Dark mode
- Toast notifications
- Skeleton loading states
- Fully responsive design
- Persistent cart using localStorage

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Axios
- Context API
- React Hot Toast
