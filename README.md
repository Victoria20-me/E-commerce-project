# MyStore E-Commerce App

A modern responsive e-commerce web application built with Next.js and Tailwind CSS.

## Live Demo

https://mye-comm.netlify.app

## Features

- Product listing
- Product details page
- Search products
- Category filtering
- Shopping cart
- Quantity management
- Wishlist functionality
- Toast notifications
- Skeleton loading states
- Dark mode
- Responsive design

## Technologies Used

- Next.js
- React
- Tailwind CSS
- Axios
- Context API
- React Hot Toast
